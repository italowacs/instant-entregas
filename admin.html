Preencha os dados do casamento e gere o arquivo da página exclusiva. O arquivo será criado no seu computador; depois, envie-o ao repositório para publicar.

Privacidade: não coloque senhas ou dados pessoais sensíveis aqui. O GitHub Pages é público; use links de vídeo/galeria com permissões adequadas no serviço onde os arquivos estão hospedados.

Depois de gerar

  1. O arquivo index.html será baixado.
  2. No GitHub, abra instant-entregas e entre em entregas (crie essa pasta se ainda não existir).
  3. Crie uma pasta com o slug escolhido e envie o arquivo para entregas/slug/index.html.
  4. Após a publicação, o endereço será https://italowacs.github.io/instant-entregas/entregas/slug/.
